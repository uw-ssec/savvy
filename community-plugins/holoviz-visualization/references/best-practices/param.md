# Param Best Practices

> Verified against Panel 1.10.0, HoloViews 1.23.2, hvPlot 0.13.0, Datashader 0.19.1, GeoViews 1.16.0, Param 2.4.2 and Bokeh 3.10.0 (Python 3.15, pandas 3.1). The Python examples were run headless against these versions.

## Overview

Param classes are the model layer of a HoloViz app. When the parameters are well declared, the class validates itself, documents itself, and generates its own UI. These practices cover validation, dependencies, documentation and inheritance in Param 2.

**Load when**: Designing a `param.Parameterized` class, a configuration object, or a reusable Panel component.

## 1. Validate Declaratively

Put constraints on the parameter itself, not in `if` checks scattered through methods. Param enforces them on every assignment, including from widgets.

```python
import param

class Query(param.Parameterized):
    table = param.Selector(objects=['sales', 'inventory'], doc='Source table')
    limit = param.Integer(default=100, bounds=(1, 10_000), doc='Maximum rows')
    ratio = param.Number(default=0.5, bounds=(0, 1), inclusive_bounds=(False, True))
    columns = param.ListSelector(default=['id'], objects=['id', 'date', 'amount'])
    owner = param.String(default='', regex=r'^[a-z_]*$')
    start = param.CalendarDate(default=None, allow_None=True)

q = Query()
try:
    q.limit = 0
except ValueError as e:
    print(e)
```

| Need | Parameter |
|------|-----------|
| One of a fixed set | `param.Selector(objects=[...])` (`ObjectSelector` is the legacy name) |
| Several of a set | `param.ListSelector` |
| Bounded number | `param.Number` / `param.Integer` with `bounds`, `softbounds` for slider range |
| Instance of a class | `param.ClassSelector(class_=...)` |
| A DataFrame with required columns | `param.DataFrame(columns={...})` |
| A button-like trigger | `param.Event` |
| Settable only at construction | `constant=True` (`readonly=True` also rejects constructor values) |

For rules that span several parameters, validate in a watcher or `@param.depends(..., watch=True)` method and raise a clear error.

## 2. Declare Dependencies Precisely

`@param.depends` tells Panel (and Param) what a method reads. List exactly those parameters. Panel re-runs the method only when one of them changes.

```python
import param

class Model(param.Parameterized):
    n = param.Integer(default=10, bounds=(1, 100))
    scale = param.Number(default=1.0)
    title = param.String(default='Result')
    total = param.Number(default=0, constant=True)

    # A view: Panel re-renders it when n or scale changes (not title)
    @param.depends('n', 'scale')
    def values(self):
        return [i * self.scale for i in range(self.n)]

    # A side effect: runs on change, even without a UI
    @param.depends('n', 'scale', watch=True, on_init=True)
    def _update_total(self):
        with param.edit_constant(self):
            self.total = sum(self.values())

m = Model()
m.param.update(n=4, scale=2.0)  # batched: _update_total runs once
print(m.total)
```

- Use `watch=True` only for side effects such as updating another parameter or writing a log. A plain view method doesn't need it.
- `on_init=True` runs the watcher once after construction, so derived state is never stale.
- Use `obj.param.update(a=1, b=2)` to change several parameters as one event. As a context manager it restores the old values on exit.
- For low-level control, `obj.param.watch(callback, ['a', 'b'])` returns a watcher you can remove with `obj.param.unwatch(watcher)`.
- For plain functions (no class), use `pn.bind` or `param.bind` instead of decorating the function with `@param.depends`.

## 3. Avoid Dependency Loops

A watcher that sets a parameter it also watches can recurse. Split inputs from outputs, and make outputs `constant` or watch-free.

```python
import param

class Converter(param.Parameterized):
    celsius = param.Number(default=0.0)
    fahrenheit = param.Number(default=32.0)

    @param.depends('celsius', watch=True)
    def _c_to_f(self):
        new = self.celsius * 9 / 5 + 32
        if new != self.fahrenheit:  # guard stops the ping-pong
            self.fahrenheit = new

    @param.depends('fahrenheit', watch=True)
    def _f_to_c(self):
        new = (self.fahrenheit - 32) * 5 / 9
        if new != self.celsius:
            self.celsius = new

c = Converter()
c.celsius = 100
print(c.fahrenheit)
```

## 4. Document Every Parameter

`doc` is the cheapest documentation you can write. It's available as `Cls.param.name.doc`, and widgets generated by `pn.Param` show it as a tooltip when the widget supports a `description` (for example `Select` and `TextInput`). `label` controls the widget caption.

```python
import param

class Smoother(param.Parameterized):
    """Apply a rolling mean to a time series."""

    window = param.Integer(
        default=7, bounds=(1, 90), label='Window (days)',
        doc='Number of days in the rolling-mean window.',
    )
    center = param.Boolean(default=False, doc='Center the window on each point.')

print(Smoother.param.window.doc)
print(Smoother.param.values())
```

## 5. Inherit Deliberately

Subclasses inherit parameters and can override any attribute of one (default, bounds, doc) by redeclaring only that attribute. Param 2 merges the rest from the parent.

```python
import param

class BaseView(param.Parameterized):
    height = param.Integer(default=300, bounds=(100, 1000), doc='Plot height in pixels.')
    title = param.String(default='View')

class TallView(BaseView):
    height = param.Integer(default=600)  # bounds and doc are inherited

print(TallView.param.height.bounds, TallView.param.height.doc)
```

- Keep shared parameters in a small base class. Don't build deep hierarchies.
- Use `param.ClassSelector` to compose objects (a `Dashboard` holding a `DataSource`). Inheritance isn't the only way to share behavior.
- Call `super().__init__(**params)` first in any `__init__` override.

## 6. Use the Param 2 API

| Legacy | Param 2 |
|--------|---------|
| `obj.get_param_values()` | `obj.param.values()` |
| `obj.set_param(a=1)` | `obj.param.update(a=1)` |
| `obj.params()` | `obj.param.objects()` |
| `param.ObjectSelector` | `param.Selector` |
| `obj.param.watch(fn, 'a')` | unchanged — still the low-level API |
